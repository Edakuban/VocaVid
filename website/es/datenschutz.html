2. Puesta a disposición del sitio web y archivos de registro del servidor

Al acceder al sitio web, el proveedor de alojamiento web trata los datos técnicamente necesarios, en particular la dirección IP, la fecha y la hora del acceso, el archivo consultado, el volumen de datos transferidos, la URL de referencia, así como información sobre el navegador y el sistema operativo. El tratamiento tiene por objeto garantizar la disponibilidad, la estabilidad y la seguridad del sitio web y se lleva a cabo en virtud del artículo 6, apartado 1, letra f) del RGPD.

3. Donaciones a través de PayPal

En este sitio web se pueden realizar donaciones voluntarias a través de PayPal. El botón de PayPal no se carga automáticamente. Solo tras hacer clic en «Cargar botón de donaciones de PayPal» se establece una conexión con PayPal y se carga el script de PayPal. En este proceso pueden tratarse, en particular, la dirección IP, la información del navegador y del dispositivo, así como datos procedentes de cookies o tecnologías similares.

El consentimiento se otorga de forma voluntaria al hacer clic. La base jurídica para la recarga y el tratamiento asociado es su consentimiento, de conformidad con el artículo 6, apartado 1, letra a) del RGPD, así como, en la medida en que sea aplicable, el artículo 25, apartado 1 de la TDDDG. Una vez cargada la página y en caso de realizar una donación, PayPal trata los datos bajo su propia responsabilidad. El proveedor es PayPal (Europe) S.à r.l. et Cie, S.C.A., 22–24 Boulevard Royal, L-2449 Luxemburgo. Encontrará información sobre el tratamiento de datos por parte de PayPal en la política de privacidad de PayPal.

4. Enlaces externos

Este sitio web contiene enlaces a servicios externos, como GitHub. La mera visita a este sitio web no implica la carga de contenidos de dichos servicios. Solo al hacer clic en un enlace abandonará este sitio web; a partir de ese momento, se aplicarán las políticas de privacidad del proveedor correspondiente.

En el marco de las disposiciones legales, tiene derecho a obtener información sobre los datos personales que le conciernen, así como a la rectificación, supresión, limitación del tratamiento, portabilidad de los datos y a oponerse a los tratamientos basados en el artículo 6, apartado 1, letras e) o f) del RGPD. Puede revocar en cualquier momento el consentimiento otorgado, con efecto para el futuro. Además, tiene derecho a presentar una reclamación ante una autoridad de control de protección de datos.
