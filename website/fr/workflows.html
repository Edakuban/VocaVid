COMFYUI · RÉFÉRENCE DES WORKFLOWS

Les workflows.
Sans deviner.

Cet aperçu a été établi à partir des fichiers JSON de workflow actuellement fournis. Les noms de fichiers et les types de nœuds sont donc précis ; pour savoir si un nœud doit être installé en tant que nœud personnalisé, le moyen le plus fiable est de vérifier avec ComfyUI Manager lors du chargement.

Voici la marche à suivre : télécharger le fichier JSON → l’importer dans ComfyUI → installer les nœuds manquants via ComfyUI Manager → placer les fichiers de modèles mentionnés ci-dessous dans les dossiers de modèles attendus par le workflow. Les fichiers JSON restent la source faisant autorité, car les dépendances entre les modèles et les nœuds peuvent évoluer.
