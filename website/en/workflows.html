COMFYUI · WORKFLOW REFERENCE

The workflows.
No guesswork.

This overview is derived from the workflow JSON files currently bundled with VocaVid. Filenames and node types are therefore concrete; when loading a workflow, ComfyUI-Manager is still the most reliable way to identify missing custom nodes.

How to proceed: Download JSON → load it in ComfyUI → install missing nodes with ComfyUI-Manager → place the model files listed below in the model folders expected by the workflow. The JSON files remain the authoritative source because model and node dependencies can evolve.
